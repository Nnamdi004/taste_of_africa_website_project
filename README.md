# Taste of Africa

Taste of Africa is a website project focused on African food, recipes, and culinary traditions. The project is intended to help visitors discover dishes and learn about the ingredients, regions, and stories connected to them.

> **Project status:** This README describes the project's purpose. Refer to the source files and configuration in the repository for the implemented features and exact development commands.

## Purpose

Food is an important expression of culture, place, and community. Taste of Africa aims to present African cuisines with curiosity and respect, and to make food-related content approachable for a broad audience. Depending on the implementation, the site may include recipes, dish profiles, ingredient information, or cultural stories.

When writing about food traditions, be as specific as possible about regional context. Africa is a diverse continent, and its cuisines should not be presented as one uniform tradition.

## Content and accessibility

- Verify cultural, regional, and ingredient details; avoid generalizations when a more precise description is available.
- Use images that are licensed or otherwise authorized for use, and credit creators when required.
- Provide meaningful alternative text for informative images. Use empty alternative text for purely decorative images when appropriate.
- Use semantic headings, descriptive links, readable color contrast, and keyboard-accessible controls.
- Keep instructions and ingredient measurements clear for the intended audience.
